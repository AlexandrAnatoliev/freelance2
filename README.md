### Чек-лист требований

#### 1. Контекст

Нужен простой независимый баннер о том, что сайт использует cookie, с кнопкой закрытия.
Основной сайт заказчика - на **1С-Битрикс**, также есть отдельный сайт-калькулятор.
Решение должно быть универсальным и вставляться на любой сайт без сложной интеграции. 
Ориентир по внешнему виду: баннер как на сайте `https://www.7778687.ru` 

#### 2. Обязательные требования 

##### 2.1 Технологии 
- [x] решение на чистом HTML + CSS 
- [x] без JavaScript
- [x] без php и серверной логики
- [x] без внешних библиотек, фреймворков и лишних зависимостей

##### 2.2 Поведение баннера
- [x] при загрузке/обновлении страницы баннер показывается
- [x] в баннере есть кнопка "хорошо"
- [x] по нажатию на кнопку баннер исчезает на текущей странице
- [ ] после обновления страницы баннер снова появляется
- [x] согласие не сохраняется между заходами
- [x] не ставить cookie
- [x] не писать в localStorage
- [x] не проверять факт согласия
- [x] не считать нажатия
- [x] не вести аналитику и логирование

<div align="center">
  <a id="intalling"></a>
  <h2>Установка</h2>
</div>

1. Откройте `cookie-banner.html`.
2. Скопируйте только фрагмент между комментариями
```
   <!-- ================= Cookie banner (start) ================= -->
```
   и
```
   <!-- ================= Cookie banner (end) ================= -->
```
   В него входят:
   - блок `<style>` со стилями баннера;
   - `<input type="checkbox" id="cookie-toggle">`;
   - `<div class="cookie-banner">…</div>` с текстом и кнопкой.
3. Не копируйте `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`, `<title>` —
   это обёртка демо-страницы, а не часть сниппета.
4. Вставьте скопированный фрагмент перед закрывающим тегом `</body>`
   на нужной странице или в шаблоне сайта.
5. Для 1С-Битрикс: вставьте в футер шаблона (`footer.php`) или в HTML-блок
   перед `</body>`.
6. Для сайта-калькулятора: вставьте перед `</body>` в основном шаблоне страницы.

Сниппет не требует подключения дополнительных файлов, JS, PHP или библиотек.

<div align="center">
  <a id="demo"></a>
  <h2>Демо</h2>
</div>

Откройте `cookie-banner.html` в браузере. Баннер появится внизу страницы.
Нажмите «Хорошо» — баннер исчезнет. После обновления страницы он снова появится.

---

<div align="center">
  <a id="how-work-it"></a>
  <h2>Как это работает</h2>
</div>

Сниппет использует скрытый `<input type="checkbox">` и `<label>`.
Клик по кнопке «Хорошо» отмечает чекбокс, а CSS-селектор 
`#cookie-toggle:checked ~ .cookie-banner` скрывает баннер.

JavaScript, cookie, localStorage и серверная логика не используются.

---

<div align="center">
  <a id="restrictions"></a>
  <h2>Ограничения</h2>
</div>

- Согласие не сохраняется между заходами и обновлениями страницы.
- Cookie и localStorage не используются.
- Баннер не является юридически полноценным механизмом согласия - 
    это только визуальное уведомление.
- Некоторые браузеры могут восстанавливать состояние чекбокса после перезагрузки. 
    Для снижения риска в разметке можно указать `autocomplete="off"` у `#cookie-toggle`.
