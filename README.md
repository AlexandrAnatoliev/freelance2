  <h2>Техническое задание</h2>

```
Нужен баннер на согласие кукки без js на html и css.
```

### Чек-лист требований

#### 1. Контекст

Нужен простой независимый баннер о том, что сайт использует cookie, с кнопкой закрытия.
Основной сайт заказчика - на **1С-Битрикс**, также есть отдельный сайт-калькулятор.
Решение должно быть универсальным и вставляться на любой сайт без сложной интеграции. 
Ориентир по внешнему виду: баннер как на сайте `https://www.7778687.ru` 

#### 2. Обязательные требования 

##### 2.1 Технологии 
- [ ] решение на чистом HTML + CSS 
- [ ] без JavaScript
- [ ] без php и серверной логики
- [ ] без внешних библиотек, фреймворков и лишних зависимостей

##### 2.2 Поведение баннера
- [ ] при загрузке/обновлении страницы баннер показывается
- [ ] в баннере есть кнопка "хорошо"
- [ ] по нажатию на кнопку баннер исчезает на текущей странице
- [ ] после обновления страницы баннер снова появляется
- [ ] согласие не сохраняется между заходами
- [ ] не ставить cookie
- [ ] не писать в localStorage
- [ ] не проверять факт согласия
- [ ] не считать нажатия
- [ ] не вести аналитику и логирование

##### 2.3 Универсальность
- [ ] код независимый и вставляется в любой сайт
- [ ] работает на айте на **Битрикс**
- [ ] работает на отдельном сайте-калькуляторе
- [ ] не конфликтует со стилями существующего сайта
- [ ] используются уникальные классы/идентификаторы

##### 2.4 Код
- [ ] максимально простой, аккуратный и компактный
- [ ] без "безобразного" и слишком большого кода
- [ ] минимум лишней разметки
- [ ] возможность вставить в нужное место страницы
- [ ] оформлен как один готовый HTML/CSS-сниппет

##### 2.5 Содержание
- [ ] текст баннера:
    - [ ] закругленные уголки
    - [ ] баннер в нижней части страницы
    - [ ] баннер поверх содержимого сайта
    - [ ] при прокручивании страницы контент перемещается, а баннер остается на месте
    - [ ] шрифт одинаковый, буквы белые
    - [ ] фон баннера - черный
    ```
    -----------------------------------------
    | Мы используем файлы                   |
    | cookie для улучшения                  |
    | работы сайта. Оставаясь     [Хорошо]  |
    | на сайте, вы соглашаетесь             |
    | с этим.                               |
    -----------------------------------------
    ```
- [ ] кнопка "Хорошо"
    - [ ] шрифт одинаковый, буквы белые
    - [ ] "Хорошо" - жирный шрифт
    - [ ] кнопка зеленая

##### 2.6 Внешний вид
- [ ] простой, аккуратный баннер
- [ ] расположен в нижней части экрана
- [ ] нормально выглядит на компьютере
- [ ] нормально выглядит на мобильных устройствах
- [ ] стиль близко к примеру `https://www.7778687.ru`, но без перегруженности 

#### 3. Что не требуется
- [ ] не запоминать согласие пользователя
- [ ] не использовать cookie для факта согласия
- [ ] не использовать JavaScript
- [ ] не использовать php
- [ ] не делать настройки баннера
- [ ] не делать кнопку "Отклонить"
- [ ] не считать количество показов или нажатий
- [ ] не интегрироваться с Битриксом глубже, чем вставка HTML/CSS кода

#### 4. Критерии приемки
- [ ] открываю страницу - баннер виден
- [ ] нажимаю "Хорошо" - баннер исчезает
- [ ] обновляю страницу - баннер снова появляется
- [ ] код не содержит JavaScript и php
- [ ] код вставлятся на страницу Битрикса и работает
- [ ] код вставлятся на сайт-калькулятор и работает
- [ ] баннер не ломает существующие стили сайта 
- [ ] код понятный и понятный
- [ ] на мобильном экране баннер не разваливается и кнопка доступна

#### 5. Формат сдачи
- [ ] готовый HTML/CSS-сниппет
- [ ] краткая инструкция: в какое место страницы вставлять
- [ ] при необходимости - отдельный демо-файл для проверки
